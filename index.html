Quiet by default.

Click to View Media treats every page like it's being read over your shoulder. Nothing is removed from the page — it just waits for your click.

Every image shape

Regular images, video, SVG images, image buttons, and likely CSS background images all get the same treatment.

Blur, on your terms

Open the toolbar popup and set blur from 18 to 100 pixels. The setting follows you across pages. Click any blurred item to reveal it, then click it again to hide it.

YouTube stays quiet

Video ads are muted when they start, your previous volume returns after, and Skip is clicked as soon as it appears.

Built for messy pages

Lazy loading, single-page navigation, and open shadow roots don't leave media behind. New content gets hidden too.

One item at a time

Every image and video toggles on its own. Reveal one and the rest of the page stays exactly as blurred as before.

Local by design

No account, no server, no telemetry. The only thing stored is your blur amount, on your device.

Install on Chrome.

Chrome extensions installed outside the Web Store live in Developer mode. Download, unzip, and point Chrome at the folder.

The extension runs locally in your browser. No account, no server, no telemetry.

Download the ZIP
  1. Download and unzip Put the folder somewhere permanent — Chrome reads it from that location.
  2. Open Chrome's extension page Go to chrome://extensions and turn on Developer mode.
  3. Load the folder Choose Load unpacked and select the unzipped folder that contains manifest.json.
  4. Set your blur Pin the extension, click its toolbar icon, and choose your intensity. Refresh open tabs to apply it everywhere.

Firefox on Android.

A local build for Firefox for Android Beta. It installs over USB with web-ext — no AMO listing, no signing, no account. Because of that, the install is temporary.

  • Firefox Beta 142+
  • Node 18+
  • USB debugging

You need Firefox Beta on the phone, Node.js on the computer, and USB debugging switched on. The add-on runs from dist/firefox.

Read the Android guide

Temporary by design. Firefox removes the add-on when the browser process ends. Re-run the command to load it again.

  1. Get the source and tools Download the repo, then run npm install once.
  2. Build the Firefox folder Run npm run build:firefox. It writes dist/firefox.
  3. Connect Firefox Beta Enable USB debugging on the phone and confirm adb devices sees it. Beta 142 or newer is required.
  4. Run it Run npm run run:android and keep the terminal open. Firefox Beta opens with the add-on loaded.
  5. Open the popup In Firefox, open the menu, then Extensions, then Click to View Media to change blur.
