try it

Quiet by default.

Click to View Media treats every page like it's being read over your shoulder. Nothing is removed from the page — it just waits for your click.

Every image shape

Regular images, video, SVG images, image buttons, and likely CSS background images all get the same treatment.

Blur, on your terms

Open the toolbar popup and set blur from 18 to 100 pixels. The setting follows you across pages.

YouTube stays quiet

Video ads are muted when they start, your previous volume returns after, and Skip is clicked as soon as it appears.

Built for messy pages

Lazy loading, single-page navigation, and open shadow roots don't leave media behind. New content gets hidden too.

Install in a minute.

Chrome extensions installed outside the Web Store live in Developer mode. Download, unzip, and point Chrome at the folder.

The extension runs locally in your browser. No account, no server, no telemetry.

Download the ZIP
  1. Download and unzip Put the folder somewhere permanent — Chrome reads it from that location.
  2. Open Chrome's extension page Go to chrome://extensions and turn on Developer mode.
  3. Load the folder Choose Load unpacked and select the unzipped folder that contains manifest.json.
  4. Set your blur Pin the extension, click its toolbar icon, and choose your intensity. Refresh open tabs to apply it everywhere.
